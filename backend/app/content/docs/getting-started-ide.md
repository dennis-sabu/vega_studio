# Getting Started with VEGA Studio

VEGA Studio is a desktop IDE purpose-built for C-DAC **VEGA ARIES V3** RISC-V firmware development.

## Modes & Workspace Regions

- **Home Mode**: Quick project launcher (`New Project`, `Open Project`, recent workspaces) and quick-jump search bar.
- **Workspace Mode**:
  - **Left Activity Bar & Sidebar** (`Ctrl+\`): Explorer, Source Control (Git & GitHub), **Examples & Docs**, SDK & Doctor, and Board Tools.
  - **Center Editor Area**: Monaco Editor tabs (`C`, `C++`, `RISC-V Assembly`, `Makefile`), Git Diff viewer, Board Manager, SDK Doctor, and the **Examples & Documentation Browser**.
  - **Bottom Panel** (`Ctrl+J`): Build Output, Interactive PTY Terminal, USB-UART Serial Monitor, Parsed Diagnostics, XMODEM Upload Output, and Shell Logs.
  - **Right Assistant Dock** (`Ctrl+Shift+A`): **Native VEGA AI Assistant**.

## Useful Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl+S` | Save active file in Monaco Editor |
| `Ctrl+\` | Toggle Left Sidebar |
| `Ctrl+J` | Toggle Bottom Panel |
| `Ctrl+Shift+A` | Toggle Right Assistant Panel |
| `Ctrl+Shift+E` / `G` | Switch to Explorer / Source Control |
| `Ctrl+,` | Open Settings Modal |
